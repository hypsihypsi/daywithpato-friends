# Kde mám kľúče?! — kamošská verzia

Chaotický deň otca, kuchára a majiteľa bistra s ADHD. Beží v prehliadači, bez inštalácie.
Postavy majú vymyslené mená a nad hlavou štítok s rolou (šéf, kuchár, čašníčka…). Zoznam „Kto je kto“ je v pauze (Esc).

Ovládanie: WASD / šípky, Shift beh, E interakcia, F mobil, Esc pauza.
